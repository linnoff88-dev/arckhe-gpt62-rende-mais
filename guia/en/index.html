The tips · a growing collection

What to do and ready-to-use text

Each tip says who it’s for. Use only what solves a problem for you. New tips are added here after they’re verified.

1

Let it run to the end any work

Without guidance, it may suggest the next step and wait. Tell it when to continue and when to stop.

Keep working until you deliver what I asked for. If the next step is within the request and you have permission, do it instead of suggesting it to me. For small uncertainties, choose an option that can be undone, proceed, and tell me what you assumed. Stop to ask only if the scope changes, you’re truly blocked, the decision is mine, or before doing something destructive or irreversible. Before wrapping up, check every part of the request.
2

Ask it to say what was left undone any work · effect unproven

The warning comes from OpenAI, which suspects it may be related to the effort to make responses concise. The text below is ours, and it hasn’t yet shown a measured improvement. In Codex, the built-in instructions already help. In another tool, we don’t know what instructions it includes, so it’s worth asking.

Before wrapping up, clearly say what wasn’t done and why: a missing file, a tool failure, denied permission, or a check that didn’t run. If something prevented the task from being completed, don’t say it’s done.
3

Ask for a self-contained answer any work

GPT-6.2 is already shorter and more direct. If you have an old "be brief" instruction, reconsider whether it still helps.

Write the final response for someone who hasn’t followed the work: start with the main point, explain enough for me to understand and decide, and don’t use nicknames or abbreviations coined during the task. If the text is for someone else, adapt it to what they know.
4

For code, teach it how the project works code only

It writes well, but it can’t guess your agreements.

Follow this project’s conventions. Reuse what already exists, and do not change what the code already does for those who depend on it unless the request requires it. Only create a new test if I ask, the project requires it, or it catches an error the current tests would miss. Prefer easy-to-read code: no crammed lines or unnecessary layers.
5

For screens and websites, show it the look you want design

Specify the type of image and font you want, or provide a reference. Then ask it to compare the result with it.

6

Start with medium effort where that setting is available

For new systems, OpenAI recommends starting at medium. For long and complex tasks, more effort may help with final checks. Look for the option near the model selection. If it doesn’t appear, skip this tip.

7

Choose between Astra and Sol any work

OpenAI recommends Astra for more demanding tasks and Sol for complex work at a lower cost.

8

Don’t rewrite the beginning halfway through the work custom systems only

This applies to anyone with a program connected directly to the model. Changing the initial instructions midway through a conversation makes the system discard its reasoning so far, and the response may get worse and cost more.

9

Clean up the old instructions any work · to test

Instructions saved in your tool or project, written for earlier models, can get in the way. For example: "ask for my approval before taking any step". Keep approval requirements before sending, deleting, paying, or doing anything irreversible. The guidance was written for GPT-6 Astra; with 6.2, it’s worth testing one change at a time.

Common questions

Before you start

Do I need to know how to code?

No. Tips 1, 2, 3, 7, and 9 are useful for people who don’t code. Tip 5 helps if you ask for screens or websites. Tip 6 only applies if your tool shows the setting. Skip tips 4 and 8.

I use ChatGPT. Does this apply?

If Astra or Sol appears in your model list, paste the text into your prompt or custom instructions. If not, you don’t need to change plans because of these tips: the text still works as general guidance, but it was designed for those models. The cited documents and our test don’t measure the effect in ChatGPT, so check the results.

What if I use another tool?

You can include the text in your request if it uses GPT-6.2. The documents and our test don’t measure the effect beyond what’s described here, so check the result.

Should I paste everything?

No. Start with the tip that addresses the problem you’re having today and see if things improve.
